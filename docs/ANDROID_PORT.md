# 鄱阳归翎 · Android 操作适配

版本：0.2.11-mobile。只导出 APK，保留电脑版的界面布局、美术、牌桌和游戏规则。仅增加左上「暂停」、开场/结局「跳过」及设置中的手机倾斜开关。

## 手机怎么玩

- **长按手牌约 0.32 秒**：显示牌的介绍、当前投入价格和效果，同时拿起这张牌。
- 接着拖动手指：沿用原来的拖牌、换位、向上出牌与向下取回规则。明显移动后说明小框收起，让出牌桌。
- 原地松手：牌回到手里，不消耗预算；说明保留到下一次点按。不要仅为看说明就拖到待执行区。
- 轻点生态指标：打开原来的指标说明，再点别处收起。
- 长按有说明的预算/科研/天赋文字：查看原来的提示。
- 图鉴与长说明：手指上下滑动；在图鉴里轻点一张牌并松手后查看详情。滑动不会误点开牌。
- 左上「暂停」打开原暂停菜单。手机系统返回键按层返回：说明 → 详情 → 图鉴/设置 → 暂停。结算或选择事件仍用屏幕上原来的按钮确认。
- 开场/结局有「跳过」。照片沿用拖动翻页与点图放大，放大页用原有箭头和关闭按钮。
- 卡牌倾斜读取手机重力与陀螺仪数据；首次握持、旋转屏幕和回到应用时自动校准。设置里可关闭。没有传感器也能玩。
- 输入地图种子时才弹数字键盘。返回先收键盘。
- 切到后台保存可保存的回合状态并暂停、静音；回来后手动继续。结算开始前保留上一个完整状态，避免把结算到一半写入存档。

| 电脑交互 | Android 处理 |
| --- | --- |
| Esc 暂停和退出详情 | 小暂停入口与系统返回，保留原菜单 |
| 手牌悬停提示 | 长按显示原提示，同时准备拖动 |
| 鼠标按住拖牌 | 直接接收单指触摸、移动、松手；保留原落点判断 |
| 鼠标移动卡面倾斜与标题视差 | 手机传感器输入，限幅和平滑，无传感器回正 |

| 预算、科研、天赋悬停 | 长按提示 |
| 图鉴按下立即打开详情 | 松手时确认点击，超过滑动阈值取消点击 |
| 滚轮浏览 | 原容器与文本面板接收手指滑动 |
| 相册鼠标悬停暂停轮播 | 手机不保留虚假的鼠标悬停，拖动与点击保留 |

| 桌面窗口退出与切换 | Android 返回、后台保存、恢复、音频与手势取消 |
| 窗口大小与高帧率 | 横屏可反转、保持完整画面比例，Android 60 FPS 上限 |

## 构建与保存

本机运行 `python tools/build_mobile.py` 准备隔离构建目录 `build/android/project`，其中会移除开发辅助插件，使用独立的电脑测试存档，不碰原来的玩家进度。Android 应用包名为 `com.poyanghu.game.mobile`，ARM64 与 ARMv7 均包含，应用内部保存离线进度。

Godot 使用本机 SDK `C:/android/sdk`、Java `C:/android/jdk17/jdk-17.0.20.1+1` 和 4.7.2 stable Android 导出模板。构建目录内有本地发布签名密钥及配置，**保留它们以便以后覆盖升级；发给朋友只发 APK，不发整个 build 目录**。该目录已被 Git 忽略，密钥不进入 APK。

导出：用 Godot 对隔离项目执行 Android release 导出，目标为 `build/android/鄱阳归翎-手机版-0.2.11.apk`。测试场景 `tests/mobile_port.tscn` 需要 `--mobile-preview`，只允许在 PoyangMobileQA 的隔离目录执行。

官方实现依据：[Godot Input](https://docs.godotengine.org/en/stable/classes/class_input.html)、[Android 导出](https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_android.html)、[Android 导出参数](https://docs.godotengine.org/en/stable/classes/class_editorexportplatformandroid.html)。

## 验证范围

测试包含原生触摸事件的长按/拖牌、原地释放与预算、真实触摸滑动图鉴、点按指标、逐层返回、后台保存与暂停、传感器数据模拟、四种窗口比例，以及完整结算并进入下一回合。另做现有电脑端结算操作回归。

当前没有连接 Android 手机。已验证的是桌面运行的同一套手机输入代码和 APK 文件结构/签名；实际手机安装、温度、长时间性能、传感器方向与手感仍需真机体验。

本次结果：手机输入 **38 项通过**，电脑端原有结算/操作 **103 项通过**。最终 APK 的签名、ZIP 对齐、包名、两种 ARM 架构及 ARM64 的 16 KB 原生库对齐均通过检查；未包含测试工具、开发辅助插件、签名密钥或玩家存档。最终 APK 中的同一套游戏资源也已在桌面实际启动，确认主菜单显示正常。

安装要求：Android 7.0（API 24）及以上、支持 OpenGL ES 3.0 的 ARM 手机。APK 大小约 **177 MiB**。这是发布签名包，发给朋友可直接安装；后续覆盖升级需要继续使用本机保存的同一把签名密钥。
